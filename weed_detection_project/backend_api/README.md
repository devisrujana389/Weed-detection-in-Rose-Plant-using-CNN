# CNN Prediction API (Python — the middleman for Java)

This is a small web server that loads your trained CNN model and answers
prediction requests. Your Java Spring Boot app will call this over HTTP.
It does not connect to Java yet — you can test it completely on its own first.

## 1. Install requirements

```bash
cd backend_api
pip install -r requirements.txt
```

## 2. Make sure your trained model exists

This API expects to find your trained model at:
```
../models/weed_detector.h5
```
(i.e., one folder above `backend_api`, inside `models/`)

If you trained it already following the earlier steps, it should already be
there. If not, go back to the main project folder and run:
```bash
python src/train.py --data_dir data/raw --model_type mobilenet --epochs 20
```

## 3. Start the API

```bash
uvicorn main:app --host 0.0.0.0 --port 5000 --reload
```

You should see:
```
Model loaded successfully from ../models/weed_detector.h5
Uvicorn running on http://0.0.0.0:5000
```

## 4. Test it — no Java needed yet

Open your browser and go to:
```
http://localhost:5000/docs
```

This gives you an interactive test page (automatically generated by
FastAPI). Steps:
1. Click on the green `POST /predict` box
2. Click "Try it out"
3. Click "Choose File" and pick a rose or weed photo from your computer
4. Click "Execute"
5. Scroll down — you'll see the JSON response, e.g.:
```json
{
  "prediction": "Weed Detected",
  "confidence": 0.8721,
  "weed_probability": 0.8721
}
```

If you see that, the API is fully working, and Java can now be pointed at
`http://localhost:5000/predict` to get predictions.

## 5. Available endpoints

| Method | URL | What it does |
|--------|-----|---------------|
| GET | `/` | Basic info message |
| GET | `/health` | Check if the API and model are alive (Java will use this) |
| POST | `/predict` | Send an image, get a prediction back |
| GET | `/docs` | Interactive test page (Swagger UI) |

## 6. What Java will eventually send

When your Spring Boot app calls this API, it needs to send a
`multipart/form-data` POST request to `http://localhost:5000/predict` with
the image attached under the field name `file`. We'll build that Java code
in the next phase.
